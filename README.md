# Prime creative portfolio prototype

Open `index.html` in a browser. The page works directly from the folder; no installation or build is needed. Keep `assets/`, `js/`, and `styles.css` alongside the HTML file. The earlier prototype remains in `old prototype/`.

The new direction combines Prime's original gradient, logos, and typography with an editorial gallery, a native-scroll square-to-portrait transition, and an uncropped creative viewer. Smaller or shorter screens can use the ratio buttons; reduced-motion preferences receive a simpler presentation.

Edit `js/creatives.js` to change the gallery's artwork, order, titles, and descriptions. Use `format: '1:1'` or `format: '4:5'`. Set `sample: false` only for approved real work. The three opening previews use the `noise`, `flow`, and `different` entries. The first portrait entry supplies the format reveal. The static HTML gallery provides a no-JavaScript fallback; update it too if that fallback needs to reflect a changed collection.

All eight current creatives are sample design studies reused from the old prototype. Real campaign artwork, final copy, publication exclusions (including Tulip), licensed webfont provenance, and final hosting/ZIP packaging remain for the finishing stage. Existing embedded fonts are reused for this local design preview; no desktop fonts were converted.
